# Ta3leemi

An educational neural network built from scratch with NumPy to classify handwritten digits.

## Project file

Open [NN by NumPy from Scratch.ipynb](./NN%20by%20NumPy%20from%20Scratch.ipynb) and run the notebook cells from top to bottom.

The notebook loads `train.csv` from the project folder, splits it into training, development, and test sets, then trains and evaluates a small neural network.

## Dataset files

- `train.csv`: labeled training images
- `test.csv`: unlabeled test images
- `sample_submission.csv`: sample prediction format

The notebook uses pandas and NumPy.
